Privacy & GDPR Statement

This utility is designed to perform BLAKE2b-512 and BLAKE3-256 cryptographic hashing locally within the user's browser environment.

Text entered into the interface and files selected for hashing are processed locally by the browser. The application does not intentionally upload submitted text or selected files to the operator's servers for hash calculation.

No registration, authentication, subscription or user account is required to use the utility.

The application does not intentionally implement advertising technologies, analytics platforms, cross-site tracking mechanisms or user profiling.

The cryptographic implementation is loaded as JavaScript code from a third-party content delivery network. Loading that code may result in ordinary technical network information, such as an IP address and request metadata, being processed by the infrastructure provider. Hash input and selected file contents are not intentionally included in those requests.

Infrastructure providers, hosting platforms, CDN providers, DNS operators and network providers may generate technical logs required for security, availability, abuse prevention and operational purposes.

Users should avoid entering highly sensitive or confidential information into any browser-based utility unless they have independently assessed the security of their browser, device, network and hosting environment.
